# Languages

Gatemate is available in English, Romanian, Spanish, French, German and Italian.

- **The first time the app opens**, it follows the phone's language (if it's one of the six; otherwise English).
- **To change it:** Profile → Language. The app restarts and every screen, date and number switches.
- The language is also saved on the account (`users.lang`), so the server sends **push alerts** (gate, delays,
  boarding, take-off, landing) and **e-mails** (confirmation code, password reset) in that language.

## How it works

- The English text is the key: `{{ 'Boarding starts' | t }}` in templates and `t('Boarding starts')` in code.
  Values go in `{name}`-style placeholders: `{{ 'Gate {gate}' | t: { gate: f.gate } }}`.
- Translations live in `i18n-src/<lang>.tsv` and are built into `public/i18n/<lang>.json`, which the app loads
  once at start-up. A text that hasn't been translated yet shows in English; nothing breaks.
- Server texts are in `backend/src/main/java/app/gatemate/common/Messages.java`; `MessagesTest` checks that every
  language has every text with the same placeholders.

## Adding or changing a text

1. Write it in English in the code, through `| t` or `t()`.
2. Add a line `@<English text>\t<translation>` to each of `i18n-src/{ro,es,fr,de,it}.tsv`.
3. Run `python3 scripts/i18n-build.py` (it fails if a `{placeholder}` was lost in a translation).
4. `python3 scripts/i18n-extract.py ro` lists the texts in the code that a language is still missing.

## Not translated (on purpose)

- Place names from OpenStreetMap (shops, terminals), city names and flight data: they're shown as published.
- The privacy policy and terms stay in English, the version that is legally binding.
